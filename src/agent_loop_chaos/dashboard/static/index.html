How to read this

What this is. Each row on the left is one experiment: we deliberately broke something while the agent was working, then watched what it did. A green dot means the agent coped. A red dot means it did not.

The middle column is everything that happened, oldest first. The highlighted rows are the moments we broke something — look at those first. Click any row to see its detail on the right.

The right column explains one moment. Diff shows exactly what changed. Verdict explains the outcome. Task is a ready-made work order you can hand to a developer or a coding agent.
